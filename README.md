## The World in One Picture — Friday 20 November 2026

One image summing up 20 November 2026's world news: 40 stories, 3 hero stories with original illustrations (Cyclone Akvan as the tall lead, Trump deferring the Iran decision to 2027, the Asian market plunge), 8 secondary news cards in a 4x2 grid, a region bar counting stories per region, an accurate world map with numbered pins 1-11 in their true places, and a 29-item summary list of further stories.

`main.py` (Python 3.13, stdlib only, no network) copies the pre-built
front-page image `entry.png` (1024×1024, under 1 MiB) to
`/output/entry.png`. Running it twice writes the same bytes.

The image is rendered from HTML/CSS (a premium newspaper front page with
original illustrations generated in-session and a public-domain world
map base) with headless Chromium, so every word is sharp and legible.
