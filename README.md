## The World in One Picture — Friday 20 November 2026

One image summing up 20 November 2026's world news: 23 stories, 3 hero stories with original illustrations (Cyclone Akvan, Trump deferring the Iran decision, the Asian market plunge), 12 Global Developments cards each date-checked 20 Nov 2026, a region bar counting stories per region, an accurate world map with numbered pins in their true places and a 20-item index.

`main.py` (Python 3.13, stdlib only, no network) copies the pre-built
front-page image `entry.png` (1024×1024, under 1 MiB) to
`/output/entry.png`. Running it twice writes the same bytes.

The image is rendered from HTML/CSS (a premium newspaper front page with
Georgia serif headlines, original illustrations generated in-session and a
public-domain world map base) with headless Chromium, so every word is sharp
and legible.
